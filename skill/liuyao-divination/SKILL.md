# 六爻占卜斷卦 · Liu Yao Divination

## Overview

六爻是以《周易》六十四卦為本、結合**月建日辰**對六爻逐爻分析的傳統占卜法。核心原則一句話：

> **先排準卦盤（機械層），再做需要推理的判斷（解讀層）。** 排盤交給引擎或嚴格按規則手工執行；解讀圍繞「用神」展開，以月日定旺衰，以動靜/空破/化變/合墓定吉凶與應期。

## When to Use

**用：** 使用者提供卦象（卦名/動爻/月日，或三枚銅錢爻象）要求斷卦、斷吉凶、斷旺衰、斷某事（姻緣/財運/事業/失物/健康…）；或要求解釋某卦盤、某技法。

**不用：** 紫微斗數、八字命理、奇門遁甲、梅花易數（不同體系，技法不通）；純哲學層面討論《易經》卦辭（那是經學，不是六爻納甲斷法）。

## Interpretation Workflow — 斷卦八步

```
排盤定盤 → 取用神 → 用神旺衰 → 世爻狀態 → 查動靜暗破 → 查化變合墓 → 綜合定性 → 定應期
```

### 第 1 步：取用神（最重要）
用神是全卦核心，取錯則全錯。常用取法見下「用神速查」。**用神臨應爻**時，用神與應爻重疊，指向明確。

### 第 2 步：用神旺衰（看月日）
- **月建**定一月內旺衰，**日辰**定當日生克沖合。兩者同權。
- 旺衰**只看月令**五行旺相休囚死（＋月日生扶比和）；**十二長生（長生/帝旺/墓/絕…）不參旺衰**，僅供取象。
- 月生日比和為旺；月剋日沖為衰。**旺衰決定用神"有沒有力"，不決定"吉凶方向"**——方向看生克關係。

### 第 3 步：世爻狀態（問卦者自身）
看世爻的六親、旺衰、是否入墓/空/破、是否發動化進化退。世爻是"你自己"，世爻退弱則自身不濟。

### 第 4 步：查動靜、暗動、空亡、月破、日破
- **動爻**：明動，力量顯，主變化。
- **暗動**：三條件——①必須是**靜爻**（日沖動爻只論動而愈動／沖散）②被**日辰六沖**③爻**旺相**→暗動；不旺相→日破。**另一條來路：靜爻得明動之爻生助，逢日沖亦作暗動（被動爻生助）。** ⭐ 最易判錯，詳見關鍵辨析。
- **空亡**：旬空之爻，旺不為真空、衰則空。動而化空、空而逢沖各有解法。**日月建本身不以空論。**
- **月破**：月建所沖之爻（如未月沖丑）。
- **日破**：日辰所沖之靜爻——旺相或得動爻生助則為**暗動**，休囚無助才是日破。

### 第 5 步：查化進化退、變爻
動爻之變：化進化退（同五行地支進退）、化空化破、化回頭生克等。化進神主增益前進，化退神主減退退縮。

### 第 6 步：查三合六合、墓庫
- **三合**：申子辰/亥卯未/寅午戌/巳酉丑，局成則合力大。**內卦三合局限初、三爻同動，外卦三合局限四、上爻同動**（動爻＋變支並見方可；二、五爻動不成局，靜爻/暗動不能頂替明動）。詳見 `references/06`。
- **入墓**：爻入五行墓庫（木墓未、水墓辰、火墓戌、金墓丑、土墓辰）。入墓主困束、暫不出頭；**墓庫待沖方出墓**。

### 第 7 步：綜合定性
合參：用神與世爻的生克關係（用神生世=吉/旺我，克世=耗損）、各方旺衰、動靜空破合墓、主變卦卦意。給出**有層次、有條件**的結論，不要一句吉凶了事。

### 第 8 步：定應期
**應期不是每卦必寫**：只有占問本身涉及時間（何時成、何時有消息、期限內能否完成），
或吉凶須以時間條件才成立時，才定應期。猜物、問來意、問東西在哪這類描述型占問，
把象翻成特徵即可，不排時間表。

- 用神/世爻**衰而待令**：等當令之月（如財爻亥水衰，待亥子月旺）。
- 入墓**待衝出墓**：如入未墓，待丑月（丑沖未）。
- 空亡**待填實/沖實**。
- 卦辭提示週期（如復卦"七日來複"）。

## Output Shape — 依占問裁剪段落

模板是給成敗型占問用的，不是每卦都要填滿。先判斷類型，再決定寫哪些段：

| 類型 | 例子 | 應期 | 建議 |
|---|---|---|---|
| 成敗型 | 求職、合作、感情、買賣、考試、官司、求財 | 寫 | 寫 |
| 時間型 | 問何時、期限、來不來得及 | 提前當主線 | 視情況 |
| 描述型 | 猜物、問東西在哪、問來意、問對方特徵 | **不寫** | **不寫** |
| 診斷型 | 問病因、問題出在哪 | 視情況 | 給調理方向 |

描述型占問的寫法：五行定材質，六神定顏色與性質，爻位定位置，卦象定形狀，旺衰定新舊
與完整程度，空破定破損或藏起；主體取應爻（所測之物），輔以所占之物的六親取象。
總斷不必勉強給成敗吉凶，也不要硬套「卡在哪」。

原則一句話：**有內容才寫**。某段在這個問題上沒有實質內容，就整段省略，不要用
「保持平常心」之類的空話補位；標題也可以改得貼題。

## Critical Distinctions — 關鍵辨析（易錯處）

### ⭐ 1. 暗動 vs 日破（最高頻錯誤）
靜爻被日辰沖，先檢查三條件：①**靜爻**（動爻被沖只論動而愈動／沖散，不算暗動）②被**日辰六沖**③爻**旺相**。
- **旺相**（月令旺/相，或得月日生扶比和）→ **暗動**：被激發，能生克他爻，**有用**，主暗中有人相助/暗中發力。
- **不旺相**，但**得明動之爻生助**（動爻五行生此爻）→ **亦作暗動**（被動爻生助）。
- **休囚且無動爻生助**（月剋日洩、死絕）→ **日破**：本弱又被沖散，**無用**。

> 旺衰只看月令（＋月日生扶比和），**十二長生不參旺衰**——不可因「自坐帝旺/臨官」就判旺相暗動。
> 例：子孫酉金在未月（未土生金，金為「相」而旺），逢卯日沖 → **暗動**（生財），**不是日破**。判錯則結論相反。
> 例：子水在卯月休囚，逢午日沖本為日破；若卦中有申金明動生水，則轉為**暗動**。

### 2. 「貴」≠「旺」
爻臨五爻君位（九五之尊）是**地位尊貴、顯要、被重視**（貴）；但力量強弱（旺）仍看月日生克。**臨君位而受月日製壓 = 貴而暫弱**，不可因"位高"就斷"力強"。

### 3. 空墓 / 出墓
- 入**空墓**（墓庫地支恰落旬空）：墓不牢，困束是虛的、易脫，非死局。
- 出墓靠**沖墓**（如未墓待丑沖），不是靠時間硬等。

### 4. 進退神方向（同五行地支）
- 進神：寅→卯、巳→午、申→酉、亥→子、丑→辰→未→戌
- 退神：卯→寅、午→巳、酉→申、子→亥、戌→未→辰→丑
- 化進主增益前進，化退主減退退縮。

### 5. 元神 / 忌神暗動
- **元神**（生用神者）暗動 → 暗中生助用神，**吉**。
- **忌神**（克用神者）暗動 → 暗中克損耗用神，**凶**。
- 判暗動時務必先定該爻是元神還是忌神。

### 6. 月破 vs 日破
- 月破 = 月建所沖（管一月）。
- 日破 = 日辰所沖之靜爻（當日）；旺相或**得動爻生助**逢日沖是暗動非破。

### 7. ⭐ 三合"虛合待用" vs 實成之局
三合論實局須**三爻齊動 / 兩動一靜 / 內外卦動變湊局**。**單爻獨動、僅借月日湊合者，只是"虛一待用之合"**——可作牽絆、有合意向的輔助參考，**不可斷"局已成、合化生世/克世"的決定性旺力**，須待流月填實方發力。最易把虛合放大為實局的合力。又兩訣：①局中之支**月破**≠局缺支——**破而待填**（破支值日月即修復），與"虛一待用"兩途；②成局則**入局從化**（從局不從性：原支之沖剋隨化而收，如巳入金局不沖亥反生水）。詳見 `references/06`。

> **內／外卦三合局的位置限定**：內卦限初、三爻同動，外卦限四、上爻同動——取兩動爻的「原支＋變支」任三支成局，且動支、變支並見；二、五爻動不成局，靜爻（含暗動）不能頂替明動。

### 8. 沖墓的雙向（應期辯證）
沖墓出墓利"入墓之爻"，但**沖墓之支可能同時克洩用神**（如沖未墓用丑，丑土克水則財亥水轉弱）。應期當取"用神得令 ∩ 墓可沖"的交集，勿只看出墓利好。墓庫配屬勿混：**水墓辰、金墓丑**（不是丑為水墓）。

### 9. ⭐ 四神（用/元/忌/仇）與「有力無力」
以**用神爻五行**為基準定四神：元＝生用、忌＝克用、仇＝克元生忌。**元神/忌神須有力方能生克用神**——元神休囚、月破、化退、入墓則"見生不生"；忌神休囚、月破、化退、入墓則"雖動不克"。判四神必同判其有力無力，勿見元神即喜、見忌神即懼。且用神須有根，無根則元有力亦難生、忌無力亦休喜。詳見 `references/09-四神與有力無力.md`。

### 10. 反吟 / 伏吟 / 卦變生克
卦變**克主卦＝大凶**（不論用神旺衰皆凶）；**反吟**（卦變相沖）主反覆動盪（成敗、得失、聚散來回）；**伏吟**（卦變而地支五行不變）主停滯呻吟。三者主整體走勢與反覆，斷長期事須查。詳見 `references/10-卦變反伏.md`。

### 11. ⭐ 象意三要素——一切皆象，同象異讀
盤面**一切要素皆可入象**：五行五性、生克、六合三合六沖、旺相休囚死、十二長生、空破墓絕、進退神、爻位世應、月建日辰、卦形勢態、六神——七層象源，一套語法。象只表達**抽象關係/態勢**（合=繫結、沖=離散、墓=收藏、死=沉寂、帝旺=鼎盛……），本身**無吉凶**；具體含義由「**象核 × 域（占事）× 角色（世/應/用/元/忌）**」合成。同一象核隨域翻轉（化退在姻緣=情淡，在疾病=**病退吉**）、隨主語反轉（合世=我與之繫結；合用神=對方被他人合走）。**孤象不定論，多象同向方定性**；六神是性質形容詞而非吉凶名詞。詳見 `references/13-象意解讀.md`。

### 12. 應期多通道交叉與應驗分層
應期不背單條口訣，看**多通道是否交匯**（動待合值 / 化變值日 / 用神值日 / 衰待當令 / 墓待沖）：≥2 通道同指=高置信時間窗；通道利好衝突（沖墓利世卻克用神）則分層辯證。斷語也應分層（關係象定"成不成"，能量象定"何時實"），應驗逐層核對、事前斷語與事後補釋分級。詳見 `references/12-應期與應驗.md`。

## Common Mistakes — 常見錯誤

| 錯誤 | 正解 |
|---|---|
| 旺相逢日沖判為日破 | 旺相逢沖是**暗動**，休囚逢沖才是日破 |
| 靜爻被日沖只論旺衰 | 三條件：**靜爻**＋**日沖**＋（旺相 或 **得動爻生助**）；動爻被沖只論愈動／沖散 |
| 自坐帝旺/臨官就判旺相 | 旺衰只看月令（＋月日生扶比和），**十二長生不參旺衰** |
| 卦中兩爻動就湊三合 | **內卦限初+三、外卦限四+上同動**（動變並見）；二、五爻動不成局 |
| 五爻君位 = 力量最強 | 君位是**貴**（地位），旺衰仍看月日 |
| 入墓一律斷凶 | 入**空墓**易脫；墓待衝出墓，未必凶 |
| 把月建當空亡論 | **日月建不以空論**；只看卦中爻是否落空 |
| 未土對木說成"生扶助旺" | 土不生木（木克土）；未對木是**墓庫收藏**，非生扶 |
| 化退神單一歸因 | 化退主退意，但成因是多象（官鬼+入墓+化退…），勿單因 |
| 一句吉凶了事 | 應給層次化、有條件的結論 + 應期 |
| 每卦都硬排應期、硬給建議 | 描述型占問（猜物、問來意）不定應期、不給建議；其餘問題才需要 |
| 卦中無空亡爻卻大談空亡 | 先查卦中爻是否落旬空，無則空亡不構成主要矛盾 |
