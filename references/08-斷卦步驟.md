# 08 · 斷卦步驟（完整工作流）

本冊把前七冊的技法串成一條**可重複的斷卦流水線**，並用本專案驗證卦例（地澤臨 → 地雷復，辛卯日）完整走查一遍。

## 一、八步流程

```
①排盤定盤 → ②取用神 → ③用神旺衰 → ④世爻狀態
→ ⑤查動靜暗破 → ⑥查化變合墓 → ⑦綜合定性 → ⑧定應期
```

| 步 | 要回答的問題 | 關鍵技法 |
|---|---|---|
| ① 排盤 | 宮屬、世應、六親、納甲、六神、動爻變卦 | 裝卦（01）；**優先用引擎** |
| ② 取用神 | 所占之事對應哪個六親？臨不臨應？ | 用神取用（02） |
| ③ 用神旺衰 | 用神在月日下有力還是無力？ | 旺相休囚死、十二長生（03） |
| ④ 世爻狀態 | 問卦者自身如何？（旺衰/入墓空破/動化） | 旺衰、墓庫（03、07） |
| ⑤ 動靜暗破 | 哪些爻動？哪些暗動/月破/日破/空？ | 動靜暗破（04） |
| ⑥ 化變合墓 | 動爻怎麼變？有無三合六合？誰入墓？ | 進退神化、合、墓（05、06、07） |
| ⑦ 綜合定性 | 吉凶方向？有層次、有條件地給結論 | 全部綜合 |
| ⑧ 定應期 | 何時轉機/成敗？（時間性占問才需） | 用神待令、出墓待沖（03、07） |

## 二、每步的關鍵提醒

- **①** 盤必須排對。動爻要找準（錯一動爻全盤錯）。用引擎核驗。
- **②** 先定"占什麼事"，再取用神。用神臨應最清晰。
- **③** 記住"旺衰≠吉凶"——旺衰定力，生克定方向。且"貴≠旺"。
- **④** 世爻是"你自己"，世爻退弱/入墓/化退，自身就不濟，再好的外緣也接不住。
- **⑤** **暗動 vs 日破務必看旺衰**——這是最高頻的錯誤。空亡先查卦中爻是否落空，無則不論。
- **⑥** 化進化退看同五行地支；回頭生克看變爻對動爻；合局看聚散；墓庫看困束與出墓。
- **⑦** 結論要分層：本質（用神與世的生克方向）+ 當下（旺衰、阻礙）+ 趨勢。不要一句吉凶了事。
- **⑧** 應期要有依據：衰待令、墓待沖、空待填。**應期不是每卦必寫**：猜物、問來意、問東西在哪這類描述型占問沒有時間軸，把象翻成特徵即可。

## 三、完整走查：地澤臨 → 地雷復（辛卯日，占家人介紹女緣是否旺己）

> 占時：丙午年 乙未月 辛卯日。男占女方（家人介紹），問是否旺己。

### ① 排盤定盤
坤宮二世卦，世在二，應在五。獨九二發動。

| 爻 | 六神 | 六親 | 納甲 | 標註 |
|---|---|---|---|---|
| 上六 | 螣蛇 | 子孫 | 癸酉金 | 靜 |
| 六五 | 勾陳 | 妻財 | 癸亥水 | 應 |
| 六四 | 朱雀 | 兄弟 | 癸丑土 | 靜 |
| 六三 | 青龍 | 兄弟 | 丁丑土 | 靜 |
| 九二 | 玄武 | 官鬼 | 丁卯木 | 世·動·化庚寅 |
| 初九 | 白虎 | 父母 | 丁巳火 | 靜 |

- 月建未、日辰卯、旬空午未。
- 動爻九二（陽）變陰，下卦兌→震，主卦臨變復卦。

### ② 取用神
男占女方 → **妻財為用**。妻財癸亥水在五爻，**臨應爻** → 用神與應重疊，指向明確，就是這個女性。

### ③ 用神旺衰
- 未月水**死**（受月建未土之克）+ 日辰卯木洩（亥生卯）→ **用神衰弱受壓**。
- 但用神**臨五爻君位**（貴）→ **貴而暫弱**：對象本身好、緣分分量重，但眼下能量沒出來、偏淡。
- 用神**生世**（亥水生卯木）→ **本質旺我**，方向吉。

### ④ 世爻狀態
世爻丁卯木，四重退守，**化退+入墓為雙重衰敗的主導**：
- 官鬼持世（憂慮負擔）
- 入未墓（月建未為木墓，且未月木囚 → 月這一側既衰又困束）
- 動化退神（卯→寅，**不可逆退氣大勢**，是核心病灶）
- 臨玄武（暗自動搖）
- **日辰卯為木帝旺比和**：僅作**保命底**——保元氣不致斷絕、使世爻屬"困中有根"而非"衰死"，但**不能扭轉化退大勢，也不負責掙脫墓鎖**（出墓靠沖墓，見⑧）。勿抬高日辰救應權重。

### ⑤ 動靜暗破
- **子孫酉金**：未月土生金、金相/冠帶 → **旺相**；逢日辰卯沖 → **暗動**（非日破！）。作元神**暗中生助亥水** → 隱性保底，主長輩介紹人暗中撮合。
- **兄弟丑土**（六三、六四）：未月沖丑 → **月破**。忌神（克財）被破 → 外部競爭/破財阻力減弱（偏好）。
- **旬空午未**：卦中六爻無落空之爻 → 空亡不構成主要矛盾（卦象實在）。世爻入之未墓落空 → **空墓**，墓不牢，困束易脫。

### ⑥ 化變合墓
- 九二**化退神**（卯→寅）：世爻力量減退、退意（不可逆退勢）。
- **三合**：亥（用神·靜）·卯（世爻·動）·未（月建）。三支雖齊備，但**僅世爻一爻獨動，亥靜、未為月建非卦爻** → 屬**虛一待用之合，非實成木局**。只可斷"有牽絆意向、緣分支在不易立刻斷"，**不可斷"木局已成、合化聚世"**；須待填實（亥子月水生木等）方發力。
- **六合卦**：變卦復為六合卦（初子四丑、二寅五亥、三辰上酉，三對皆合），主和合、聚攏、持久；臨（非六合）變復（六合），由散轉合，於姻緣為正面之象。然"用神有氣方濟"，用神亥水衰，須待旺月（亥子月）合力方顯。（引擎 `board.changed_is_liuhe`）

### ⑦ 綜合定性
**本質旺你**（用神生世 + 臨君位）——好緣分，對象不差且分量重。（三合為虛合待用，不作決定性旺力，僅作牽絆輔助參考。）
**當下不旺**：用神衰弱受壓（感情能量弱、對方未發力）+ 世爻"化退+入墓"雙重衰敗為主導（日辰僅保命底）+ 子孫暗動暗中保底（隱性，不顯）。
→ 緣分實而時機未至、有底子卻暫封存；退勢為主、困中有根。宜守宜養，不宜急進亦不宜放棄。

### ⑧ 定應期（須雙向辯證）
- **感情（財亥水）最佳時間窗**：**亥、子月**（初冬、仲冬，水當令）——財最旺、女方最有力，且世爻雖未出墓但有日辰根保底。**這是雙方相對重疊的利好時間窗。**
- **世爻出墓發力**：**丑月**（丑沖未開木墓）——利你自身狀態回勇。**但注意錯位**：丑月土當令克水、水氣將退，財爻此時已轉弱 → "你行她退"。
- 故勿籠統說"丑月發力即好轉"；**真正要把握的是亥子月**。卦變復，主慢、重新蓄力、否極泰來（七日來複）。

### 結論
好緣分、能旺你、對象不差且分量重；當下"貴而暫弱"、元神暗動暗中保底、世爻"化退+入墓"雙重退守（日辰保底、非解藥）——緣分實而時機未至、退勢為主。**最佳時間窗在亥子月**（財旺、雙方較有利）；丑月你出墓但財已轉弱，須防時間錯位。

## 三·補、應期總注（《增刪卜易·各門類應期總注章》）

斷卦功夫過硬，全在應期準確。下為主流應期斷法整合，按主事爻（用神/世爻）狀態分類——核心口訣：**靜待沖值、動待合值、旺待墓沖、衰待生旺、墓待沖、合待沖、破待填、空待填沖**（缺什麼補什麼、被什麼制待什麼解）。

| 主事爻狀態 | 應期 | 例 |
|---|---|---|
| **靜** | 逢值、逢沖 | 臨子水不動，後逢子日(值)或午日(沖)應 |
| **動** | 逢合、逢值 | 臨子水發動，後逢子日(值)或丑日(合)應 |
| **太旺**（多見/臨月日） | 逢墓、逢沖 | 臨午火又遇巳午，後逢亥子(沖)或戌(墓)應 |
| **衰絕** | 遇生、遇旺 | 金爻休囚於巳午月，後逢土月生或秋令旺應 |
| **入三墓** | 喜沖開 | 午火墓於戌，後逢辰日(沖戌)應 |
| **逢合（合住）** | 宜沖開 | 子與丑合，後逢午未日(沖開)應 |
| **月破** | 喜填合 | 子月午火月破，後逢未日(合)或午日(填實)應 |
| **旬空** | 最愛填沖 | 空亡爻逢同支日(填實)或沖日應 |
| **大象吉而受克** | 待克神受克 | 用神辰土旺但受寅卯克，後逢申酉(克木)日應吉 |
| **大象凶而受克** | 防克者逢生 | 用神衰又受克，克神逢生之時凶應 |
| **化進神** | 逢值、逢合 | 申動化酉，應申(值)月日 |
| **化退神** | 忌值、忌沖 | 酉動化申退，應申(值)或寅(沖)月日 |

### 其他應期要點
- **元神忌神**：元神來助看用神衰旺（用衰須元旺方生得起）；忌神來克觀元氣興衰（忌旺則克成、忌無力則不克）。
- **獨發獨靜**：間有應於卦中獨發或獨靜之爻。
- **變爻動爻**：如爻臨戌變酉，有成日(值變爻)或酉日應。
- **遠近**：遠事定年月，近事應日時；亦有占遠應近、占近應遠、占月應年、占日應時者。
- **世空元動**：須待元神逢值（如甲辰旬占財得困之坎，主亥日得財）。
- **世衰元靜**：必須元氣逢沖（如秋占圖謀得困卦，後逢巳日成）。
- **卦不明**：恍惚難斷者，再占一卦合決，不可妄斷。

> 本卦例應用：用神亥水衰 → 待**亥子月（逢旺）**；世爻入未墓 → 待**丑月（沖墓）**。但須雙向辯證（見走查⑧）：亥子月財旺是感情最佳時間窗，丑月世出墓卻財轉弱，須防錯位。

## 四、輸出規範

一份合格的斷卦輸出應包含：

1. **排盤**（表）+ 關鍵引數（月日空用神）。
2. **本質判斷**：用神與世爻的生克關係定大方向。
3. **當下分析**：旺衰、動靜暗破、化變合墓，逐項點明，**關鍵辨析處（暗動/空墓/進退）要講清依據**。
4. **綜合定性**：分層、有條件的結論，不一刀切。
5. **應期**：有依據的時間窗；**時間性占問才寫**，描述型占問（猜物、問來意、問東西在哪）不寫。
6. **建議**：能從卦理推導出行動或心態選擇時才給；描述型占問沒有可操作建議，整段省略，不必用空話補位。
7. **理性提醒**：術數非科學，結論供參考；涉及健康、法律、重大財務、婚姻時才附。

段落是為問題服務的：某段在這個占問上沒有實質內容就整段不寫，標題可依問題改寫。

## 五、理性提醒

六爻為傳統文化與占卜術，斷的是"勢、象、時機"，非事實預測。任何決策（感情、財務、健康等）須以現實理性判斷為準，占卜僅作心態與時機之參考。
