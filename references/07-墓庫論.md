# 07 · 墓庫論

"墓庫"是爻的一種特殊狀態——力量被封存、被收藏、暫不能發揮作用。本次專案驗證卦例中，世爻"入未墓"是核心病灶之一；而"入空墓"與"出墓"的細節，是常被忽略卻關鍵的判讀點。

## 一、五行墓庫

每個五行都有一個"墓庫"地支（辰戌丑未四庫）：

| 五行 | 墓庫 | 三合局印證 |
|---|---|---|
| 木 | **未** | 亥卯**未** |
| 火 | **戌** | 寅午**戌** |
| 金 | **丑** | 巳酉**丑** |
| 水 | **辰** | 申子**辰** |
| 土 | 辰 | （土寄水庫） |

> 記憶：墓庫就是該五行三合局的"庫"那一位。

> ⚠️ **墓庫配屬切勿搞混**（斷應期、入墓時常錯處）：
> - 水 → **辰**（不是丑！丑是金墓）
> - 金 → **丑**（不是辰）
> - 木 → 未，火 → 戌，土 → 辰
> 即：**亥水/子水之墓在辰**；申金/酉金之墓在丑。沖某五行之墓，要先查對該墓庫地支，再論沖墓出墓的雙向影響（沖墓之支可能同時克洩用神，見下"出墓的雙向"）。

## 二、爻如何"入墓"

一個爻的五行，其墓庫地支若出現在以下位置，則該爻**入墓**：

1. **入月墓**：月建地支為該爻墓庫。
2. **入日墓**：日辰地支為該爻墓庫。
3. **入動墓**：卦中動爻之地支為該爻墓庫。
4. **入化墓（自化墓）**：動爻變出之爻為本身墓庫。

> **經典例**：世爻卯木，木墓在未；月建為未 → **世爻入月墓（未墓）**。

## 三、墓庫的兩面：庫 vs 墓

| 爻的狀態 | 墓庫的性質 | 含義 |
|---|---|---|
| 爻**旺相**入墓 | 為"**庫**"（庫藏） | 有歸宿、有儲藏，是收束歸藏，未必凶；旺者入庫如寶入庫 |
| 爻**衰弱**入墓 | 為"**墓**"（墳墓） | 被困束、衰敗、力量被封存、暫不出頭 |

實務中多統稱"入墓"，主：**困束、收藏、施展不開、暫不能發揮作用、力量被封存**。

## 四、關鍵辨析

### 1. 墓庫是"收藏"，不是"生扶"
某五行之墓庫（如木墓未），其本身五行仍屬土。**土不生木（木克土）**。故"未土對木"是**墓庫收藏**關係，**不是生扶助旺**——生扶木的是水（水生木）。勿把墓庫當生扶。

### 2. ⭐ 空墓（墓庫落空亡）— 易脫之困
若墓庫地支**恰落旬空**（如未墓，而未落空亡），則：

- **墓不牢、墓是虛的** → 困束帶"虛驚"性質，**容易掙脫**，非死局。
- 這與"爻本身有強根（如得日辰比和）"互相呼應：**困是暫困、可解之困**。

> **經典例**：世爻卯木入未墓，而未恰落旬空（辛卯日甲申旬空午未）→ 世爻入的是**空墓**，墓不甚牢，困束帶虛、易脫。故斷"暫困可解"，非衰敗死局。

### 3. ⭐ 出墓（待沖）
入墓之爻**不能自己出來**，要靠**沖墓**（沖開墓庫）方能出墓、重新發揮作用：

- 沖墓 = 用與墓庫相沖的地支。如入未墓，待**丑**（丑未沖）沖開。
- 出墓的時機：沖墓之**月**、之**日**，或卦中有力的沖墓之**動爻**。

> **經典例**：世爻入未墓，待**丑月**（丑沖未）沖開墓庫，世爻方能出墓、狀態回勇、能主動發力。這與"用神待令"的應期常疊合。

### ⭐ 沖墓的雙向影響（應期辯證，勿只看利好）
沖墓出墓雖利"入墓之爻"解脫，但**沖墓之支本身對其他爻（尤其用神）可能同時不利**，須雙向看：

- 沖未墓用的是**丑**。丑屬土，**土克水**；且丑為季冬末、水氣將退。
- 故本例中，丑月雖開木墓讓世爻（卯木）出墓，但對**妻財亥水**（財/她）是"土克水 + 水氣衰退" → **財爻在丑月轉弱**。
- 結果是**時間錯位**：財（感情）最旺在**亥、子月**（水當令），世爻出墓發力卻偏在**丑月** → "你狀態回來時，她/感情能量已過峰值"。斷應期須點明此錯位，**最佳重疊時間窗在亥子月**（財旺，世爻雖未出墓但有日辰根保底），而非籠統說"丑月發力"。

> 通則：**沖墓之支若同時克洩用神，則"出墓利好"與"用神轉弱"並存**，應期當取用神得令且墓可沖的交集，而非單看一處。

## 五、入墓的吉凶

入墓本身是"力量被封存"的中性狀態，吉凶看：

1. **誰入墓**：
   - 用神/世爻入墓 → 所占之事或自身被困束、暫難發揮（偏負）。
   - 忌神入墓 → 忌神被收藏不能為害（偏正）。
2. **旺衰**：旺入庫（有藏有出），衰入墓（衰敗被困）。
3. **是否空墓**：空墓易脫，損害輕、可解。
4. **能否出墓**：有沖墓之機則終能出，事有轉機；無則長期困頓。

## 六、速查

| 狀態 | 含義 |
|---|---|
| 旺爻入墓 | 入庫，歸藏，有出 |
| 衰爻入墓 | 入墓，困束，衰敗 |
| 入空墓 | 墓虛，困束易脫，非死局 |
| 待衝出墓 | 沖墓之月/日出墓發力 |
| 忌神入墓 | 忌神不能為害，反吉 |
