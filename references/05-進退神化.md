# 05 · 進退神化

動爻必變，變出之爻（變爻/化神）與動爻的關係，決定了動爻力量的增減與事情的進退走向。

## 一、化進神 / 化退神（同五行地支）

動爻與變爻為**同五行**的地支時，論進退神（看地支在該五行序列中的進退方向）。

| 五行 | 進神（前進） | 退神（後退） |
|---|---|---|
| 木 | 寅 → 卯 | 卯 → 寅 |
| 火 | 巳 → 午 | 午 → 巳 |
| 金 | 申 → 酉 | 酉 → 申 |
| 水 | 亥 → 子 | 子 → 亥 |
| 土 | 丑 → 辰 → 未 → 戌 | 戌 → 未 → 辰 → 丑 |

（土按四庫順序，丑→辰→未→戌為進，反之為退。）

- **化進神**：力量增益、前進、發展、壯大、越動越好。
- **化退神**：力量減退、後退、退縮、衰減、越動越弱，主退意、放棄、勢微。

> **經典例**：世爻丁卯木動，化庚寅木。卯→寅為**退神**。世爻動而化退，主自身力量減退、心氣在退、有打退堂鼓之意。

**進退神只論同五行地支。** 若動爻與變爻五行不同（如木變金），不論進退，而論回頭生克（見下）。

## 二、化回頭生 / 化回頭克

變爻（化神）回頭作用於動爻本身：

| 關係 | 名稱 | 含義 |
|---|---|---|
| 變爻**生**動爻 | 化回頭生 | 得生扶，力量增強，吉（用神化回頭生尤吉） |
| 變爻**克**動爻 | 化回頭克 | 受剋制，力量受損，凶（用神化回頭克主事敗） |
| 變爻與動爻**同五行但非進退**（如寅化寅） | 化比和 | 力量維持，無明顯增減 |

> 例：寅木動化酉金——金克木，為**化回頭克**，木爻受損，主事情反而變糟。
> 例：寅木動化子水——水生木，為**化回頭生**，木爻得生扶，主事情得助。

## 三、化空 / 化破 / 化墓

變爻本身的狀態也會影響動爻的成敗：

- **化空**：變爻落旬空。動而化空，主事將有變卻落空、暫時不能落實，待變爻填實（出空之日/月）方成。用神化空多主虛象、暫不成。
- **化破**：變爻為月破或日破。動而化破，主變出之物無用、事將變而覆敗。
- **化墓**：變爻入墓（見 07）。動而化墓，主事被收藏困束，待沖墓方出。

> 三者共同含義：**動爻雖動，但變爻本身殘缺/落空/被困，則變化不能落實**，事情多中途有變或暫不能成，須待變爻得救（填實/出破/出墓）。

## 四、動爻變化的實務判讀

排盤後看每個動爻，依次問：

1. 變爻與動爻**同五行**嗎？
   - 是 → 論**進神/退神**（增力或減力）。
   - 否 → 論**回頭生/回頭克/比和**。
2. 變爻**本身空、破、入墓**嗎？
   - 是 → 變化不能落實，待救應。
3. 綜合：動爻是**越動越好**（化進/化回頭生/變爻旺實）還是**越動越差**（化退/化回頭克/化空破墓）。

## 五、動爻吉凶速查

| 動爻變化 | 趨勢 |
|---|---|
| 化進神 / 化回頭生 / 化旺 | 越動越好，增益、前進 |
| 化退神 / 化回頭克 / 化衰 | 越動越差，減退、受損 |
| 化空 / 化破 / 化墓 | 變化不能落實，暫不成，待救 |
| 化比和 | 維持現狀 |
