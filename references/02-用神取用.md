# 02 · 用神取用

**用神**是全卦核心——所占之事對應的那個六親爻。取對用神，斷卦方向才對；取錯，旺衰斷得再細也白費。

## 一、六親對應的占事

| 六親 | 主占之事 |
|---|---|
| **父母** | 父母長輩、祖業、文書、契約、學歷、考試、房屋、土地、車輛、舟車、衣物、雨、辛勞 |
| **兄弟** | 兄弟姐妹、同輩朋友、合夥人、競爭者、劫財破財之事、同僚 |
| **子孫** | 子女晚輩、下屬、學生、醫藥（治病看子孫）、福神、僧道、寵物、六畜、娛樂、解憂之神（子孫剋制官鬼，主消災） |
| **妻財** | 妻子、女友、錢財、財物、糧食、收成、傭人、晴（測天看財為晴） |
| **官鬼** | 丈夫、男友、官職、工作、功名、領導、盜賊、憂慮、疾病、官非、雷霆、雷電 |

## 二、常用取法

| 占問 | 用神 |
|---|---|
| 占父母/長輩吉凶 | 父母 |
| 占子女/晚輩 | 子孫 |
| 占夫妻（男占妻、女占夫） | 男看妻財，女看官鬼 |
| 占戀愛對象（男占女/女占男） | 同上：男看妻財，女看官鬼 |
| 占財運、求財、生意 | 妻財（輔看子孫為財源） |
| 占考試、求職、升遷、官運 | 官鬼（功名）+ 父母（文書） |
| 占疾病 | 官鬼為病（也看子孫為醫藥、為解神） |
| 占官司、官非 | 官鬼 |
| 占失物、盜賊 | 官鬼（賊）+ 妻財（物） |
| 占行人、出行 | 看應爻或用神（行人之爻視關係定） |
| 占合夥、競爭 | 兄弟 |
| 占蓋房、買房 | 父母（房屋） |
| 占他人、泛占某事無特定六親 | 應爻 |
| 占猜物、問來意、問對方特徵、問事情性質 | 應爻（所測之物），輔以六親五行、六神、爻位取象 |

> **描述型占問**（猜物、問來意、問東西在哪、問對方長相／性格）不以吉凶成敗為主，
> 也無所謂應期與建議。取應爻為所測之物，把五行（材質）、六神（顏色與性質）、
> 爻位（位置）、卦象（形狀）、旺衰（新舊與完整程度）、空破（破損或藏起）逐一翻成
> 具體特徵即可。

## 三、用神與世、應的關係

- **世爻** = 問卦者自己（自占吉凶以世爻為主體）。
- **應爻** = 對方 / 所測的物件或事。
- **用神臨應爻**：用神與應爻重疊，指向明確，是好事——說明所測之人/事與用神一致。
- **用神與世爻的生克**決定吉凶方向：
  - 用神**生世**、**合世** → 有利、旺我、吉。
  - 用神**克世**、**沖世** → 耗損、壓力、不吉（除非占官鬼求官等用神本宜克我之類）。
  - 世爻**生用神** → 自己付出、費力。
  - 世爻**克用神** → 自己剋制所測之物。

## 四、用神不上卦（伏神）

若所佔用神在主卦六爻中**沒有出現**（不在卦上），稱為"用神不上卦"，需尋**伏神**：

- 在本宮八純卦（首卦）中找到該六親所在之爻，即為伏神，伏於主卦某爻之下。
- 飛神 = 主卦上承載伏神的那個爻。
- 伏神要"得出"（飛神空、破、被克，或日月生扶伏神）才能成用；若伏神被飛神壓制、且衰弱無氣，則所求難遂。

> 實務中用神不上卦多主事情不順、所求之人或事目前缺位或難現。引擎目前以顯用神為主；伏神需手工詳參。

## 五、取用神的關鍵提醒

1. **先定占什麼事，再定用神**——同一卦，問財與問病用神不同。
2. **用神取定後，全卦圍繞它轉**：旺衰看它、生克看它、應期看它。
3. **勿把應爻當用神混用**——應爻是"對方這個位置"，用神是"所占之事對應的六親"。二者重合時最清晰，不重合時要分清（比如男占女友，用神是妻財爻，而應爻可能是女友也可能是別人，以妻財為準）。
4. 占**自身整體吉凶**、**謀事成敗**無特定物件時，以**世爻**為主來看。
