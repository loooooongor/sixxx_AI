# 12 · 應期與應驗

08 冊應期總注給出的是**單通道法則**（靜待沖值、動待合值、化退忌值……）。本冊講更進一層的四件事：

> **多通道交叉定位（何時）→ 化出之支定事性（何事何性）→ 應驗分層核對（應沒應）→ 驗卦覆盤（斷後校準）。**

斷卦的功夫在斷前，校準的功夫在斷後——沒有驗卦循環的應期法則只是口訣。

## 一、應期多通道交叉定位（何時）

單通道法則見 08·三·補。實務中**一個卦往往同時開通多條通道，通道交匯處即高置信應期**：

| 通道 | 法則（摘自 08 總注） | 本卦例 |
|---|---|---|
| 動待合值 | 動爻逢合神之日/月 | 世爻卯動 → 合神戌 → **戌月** |
| 化變值日 | 動爻應於變爻值日（化退亦逢值而應） | 卯化寅 → **寅日** |
| 用/世值日 | 主事爻本位值日 | 世爻卯 → **卯日** |
| 衰待當令 | 用神衰 → 當令之月（時間窗） | 亥水衰 → **亥子月** |
| 墓待沖 | 入墓 → 沖墓之月（防錯位） | 卯入未墓 → **丑月**（丑土克水，財同轉弱） |
| **破待填 → 局成** | 局中月破之支值令填實、所待之支臨日建——三合成實，**備用管道接棒**（用神失令之月的生扶強脈沖；局法見 06 冊「局之進階」） | 巳酉丑金局：**丑月**填實破支、**巳日**臨值成局化金 → 生亥生扶 |

**置信度分級：**

- **高置信**：≥2 通道指向同一時間窗 → 可明言時間窗。
- **候選**：單通道 → 只作候選，標註前提條件。
- **辯證**：通道利好互相沖突（如沖墓利世、卻克用神）→ 不取單一"好月份"，分層給出（見 08 走查⑧、SKILL 辨析 8）。

> 本卦例（占於未月辛卯日，事驗於戌月戊寅、己卯兩日）：世爻動而合神值**月**（戌）、變爻值**日**（寅）、世爻值**日**（卯）——三通道交匯，應期落點精確到兩日之內。這是"多通道交叉"優於單通道背誦的直接例證。

## 二、化出之支的多重身份（何事、何性）

08 總注言"**化退神忌值、忌沖**"——化退之爻，其事多應在**變爻值日/沖日**兌現。但兌現的**是什麼性質的事**，須並看化出之支的**三重身份**：

| 身份 | 看什麼 | 主什麼 |
|---|---|---|
| **氣機** | 進神/退神 | 勢的方向（進=增益前進，退=消退退縮） |
| **損益** | 回頭生克 | 變爻對動爻本身的生克 |
| **落點** | 與用神/世爻的六合六沖 | 變化最終**繫結誰、成全誰** |

**⭐ "退而得合"**：化退主退，但化出之支若**六合用神（或世爻）**，則此"退"以"合"落實——主動退讓反成全結合；應期仍取變爻值日，事性卻是正面的和合。反之，化進而化出之支沖剋用神，則是"進中有損"。**化進≠吉、化退≠凶，三重身份並看方能定性。**

> 本卦例：世爻卯化寅（退神），而寅**六合用神亥水**——應驗於寅日（變爻值日，合法則），兌現的是關係確立（合象落點）。問卦者一方主動放低赴約（退象氣機），退而成其合。若機械套"化退=凶"，此卦全盤誤讀。

## 三、應驗分層（應沒應）

卦的結論是**一組條件**（合象已動、用神未當令、墓未沖開……），應驗也必是**分層的**，不是成/敗二值。方法三步：

1. **拆層**：把占事拆成遞進層次。姻緣例：牽絆 → 關係確立 → 同住 → 親密之實 → 全實/婚成。
2. **對條件**：每層對應卦象條件——條件已備=可應；條件含"待時"=待應。
3. **逐層核對**：應驗時記錄哪層已應、以何通道應。

| 層次 | 卦象條件 | 本卦例 |
|---|---|---|
| 牽絆不斷 | 亥卯未虛合 + 變卦六合 + 日建根 | 持續在 |
| 關係確立 | 化出寅合用神亥（落點）+ 合神值月 | **已應**（寅日） |
| 同住 | 世爻被月建合住（卯戌合）+ 應臨勾陳（安定久留） | **已應**（戌月） |
| 親密之實 | 動爻爻辭"鹹臨"——鹹者感也，以感相應 | **已應** |
| 全實 | 用神亥水**當令**（亥月方旺）+ 世爻未出未墓 | **待亥月**（占時明斷"亥子月最佳時間窗"） |

**原理**：分層應驗是"緣分實而未至其時"這類分層結論的忠實對映。**占時把層與條件寫清，驗卦時才有得核對**——這也倒逼斷卦輸出分層化、條件化（見 08·四 輸出規範），拒絕"一句吉凶了事"。

## 四、驗卦覆盤法（斷後校準循環）

1. **釘死事實**：事件公曆日期 → 干支（年/月/日）；事實內容按層記錄。
2. **逐象對應**：每條斷語 → 對應通道（值/合/沖/填/當令/分層），列成對照表。
3. **證據分級**（⭐ 誠實是校準的前提）：
   - **強證據**：**事前**寫下的斷語（verdict、應期表）事後兌現。本卦例"最佳時間窗在亥子月"寫於占時未驗之前，屬事前斷語。
   - **弱證據**：應驗之後**補做**的對應解釋（事後補釋）。事後解讀天然有彈性，只作參考、不得冒充驗證。
4. **歸檔**：匿名版進 `examples/`（可附應驗標註）；涉真實姓名/地點/隱私的記錄進 `private/`（已被 `.gitignore` 排除，永不提交）。
