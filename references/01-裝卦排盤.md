# 01 · 裝卦排盤

排盤是斷卦的根基。盤排錯，後面全錯。本冊講如何把一個卦"裝"完整：定宮、定世應、納甲、配六親、配六神、找動爻變爻。

> 實踐中**優先用引擎排盤**（`python src/paipan.py …`），手工裝卦僅作理解與核驗。

| 卦 | 符 | 自然 | 五行 | 方位 | 陰陽 | 爻象(自下而上) |
|---|---|---|---|---|---|---|
| 乾 | ☰ | 天 | 金 | 西北 | 陽 | 陽陽陽 |
| 兌 | ☱ | 澤 | 金 | 西 | 陰 | 陽陽陰 |
| 離 | ☲ | 火 | 火 | 南 | 陰 | 陽陰陽 |
| 震 | ☳ | 雷 | 木 | 東 | 陽 | 陽陰陰 |
| 巽 | ☴ | 風 | 木 | 東南 | 陰 | 陰陽陽 |
| 坎 | ☵ | 水 | 水 | 北 | 陽 | 陰陽陰 |
| 艮 | ☶ | 山 | 土 | 東北 | 陽 | 陰陰陽 |

記憶：乾三連、坤六斷、震仰盂、艮覆碗、離中虛、坎中滿、兌上缺、巽下斷。

## 二、八宮與五行

六十四卦分屬八宮，每宮以一個八純卦為本宮，**宮的五行即本宮卦的五行**：

| 宮 | 本宮卦 | 五行 |
|---|---|---|
| 乾宮 | 乾為天 | 金 |
| 兌宮 | 兌為澤 | 金 |
| 離宮 | 離為火 | 火 |
| 震宮 | 震為雷 | 木 |
| 巽宮 | 巽為風 | 木 |
| 坎宮 | 坎為水 | 水 |
| 艮宮 | 艮為山 | 土 |
| 坤宮 | 坤為地 | 土 |

每宮八卦由本宮卦"變爻"而來，順序固定：

1. **本宮卦**（八純）
2. **一世**：初爻變
3. **二世**：初、二爻變
4. **三世**：初、二、三爻變
5. **四世**：初至四爻變
6. **五世**：初至五爻變
7. **遊魂卦**：四爻變回本宮
8. **歸魂卦**：下卦恢復本宮

**示範（乾宮）**：乾為天 →(初變) 天風姤 →(二變) 天山遁 →(三變) 天地否 →(四變) 風地觀 →(五變) 山地剝 →(四回) 火地晉(遊魂) →(下回) 火天大有(歸魂)。

> 查任意一卦屬何宮、何世，最穩妥用引擎：`python src/paipan.py --hexagram 地澤臨 …` 會輸出宮屬與世爻。手工核對可按上法逆推。

## 三、世應

**世爻**代表問卦者自身（或所測主體），**應爻**代表對方/所測之事。世應相隔兩爻（隔三位）。

**世爻口訣**：

| 卦類 | 世爻位置 |
|---|---|
| 八純（六世） | 上爻（六爻） |
| 一世 | 初爻 |
| 二世 | 二爻 |
| 三世 | 三爻 |
| 四世 | 四爻 |
| 五世 | 五爻 |
| 遊魂 | 四爻 |
| 歸魂 | 三爻 |

應爻 = 世爻隔兩爻（世初→應四，世二→應五，世三→應上，世四→應初，世五→應二，世上→應三）。

> 例：地澤臨為坤宮二世卦，**世在二爻，應在五爻**。

## 四、納甲（天干地支）

每個卦的上下兩個八卦各納一個天干，六爻再配地支。

**八卦納干**：

| 八卦 | 內卦(下) | 外卦(上) |
|---|---|---|
| 乾 | 甲 | 壬 |
| 坤 | 乙 | 癸 |
| 坎 | 戊 | 戊 |
| 離 | 己 | 己 |
| 震 | 庚 | 庚 |
| 巽 | 辛 | 辛 |
| 艮 | 丙 | 丙 |
| 兌 | 丁 | 丁 |

**地支配法**：陽卦（乾坎艮震）地支**順行**，陰卦（坤巽離兌）地支**逆行**；陽卦配陽支序、陰卦配陰支序。完整六爻納甲表：

| 八卦 | 內卦(初/二/三) | 外卦(四/五/上) |
|---|---|---|
| 乾 | 甲子 甲寅 甲辰 | 壬午 壬申 壬戌 |
| 坤 | 乙未 乙巳 乙卯 | 癸丑 癸亥 癸酉 |
| 坎 | 戊寅 戊辰 戊午 | 戊申 戊戌 戊子 |
| 離 | 己卯 己丑 己亥 | 己酉 己未 己巳 |
| 震 | 庚子 庚寅 庚辰 | 庚午 庚申 庚戌 |
| 巽 | 辛丑 辛亥 辛酉 | 辛未 辛巳 辛卯 |
| 艮 | 丙辰 丙午 丙申 | 丙戌 丙子 丙寅 |
| 兌 | 丁巳 丁卯 丁丑 | 丁亥 丁酉 丁未 |

> 例：地澤臨 = 上坤下兌。下兌內卦：初九丁巳、九二丁卯、六三丁丑；上坤外卦：六四癸丑、六五癸亥、上六癸酉。

## 五、六親

以**本宮五行**為"我"，定六親：

| 關係 | 六親 |
|---|---|
| 生我者 | 父母 |
| 我生者 | 子孫 |
| 克我者 | 官鬼 |
| 我克者 | 妻財 |
| 比和者（同我） | 兄弟 |

**示範（坤宮，我=土）**：火生土→父母；土生金→子孫；木克土→官鬼；土克水→妻財；土同土→兄弟。

故地澤臨（坤宮）六親：丁巳火=父母、丁卯木=官鬼、丁丑土=兄弟、癸亥水=妻財、癸酉金=子孫。

## 六、六神（神煞）

以**日干**起，六神固定順序為：青龍→朱雀→勾陳→螣蛇→白虎→玄武，從**初爻**起逐爻上行。

**日干起例**：

| 日干 | 初爻起 |
|---|---|
| 甲、乙 | 青龍 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陳 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

六神性情：青龍主喜慶桃花；朱雀主口舌是非訊息；勾陳主拖延牽纏舊事；螣蛇主虛驚怪異糾纏；白虎主血光兇險剛猛；玄武主闇昧隱私欺騙。

> 例：辛卯日，庚辛起白虎於初爻。地澤臨：初九白虎、九二玄武、六三青龍、六四朱雀、六五勾陳、上六螣蛇。

## 七、動爻與變卦

- **動爻**：占卦時老陽（⃝）或老陰（✕）之爻，主變化。陽動變陰，陰動變陽。
- **變卦**：動爻陰陽改變後所得的新卦。一卦可有多個動爻，皆變。
- 動爻之"變"產生：化進化退、化空化破、化回頭生克、化墓等（見 `05-進退神化.md`）。

> 例：地澤臨九二（陽）動，變陰，下卦兌(☱)變震(☳)，全卦成地雷復。九二丁卯動化復卦六二庚寅。
