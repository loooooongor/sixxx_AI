# 06 · 三合六合

"合"主和合、牽絆、聚集。合能把分散的力量聚成一股（三合成局），也能把爻絆住不動（合住）。合與沖相對：沖主動盪散開，合主聚集糾纏。

## 一、三合局

三合局由三個地支合成一股五行之力：

| 三合 | 化局 | 中神 |
|---|---|---|
| 申 · 子 · 辰 | 水局 | 子 |
| 亥 · 卯 · 未 | 木局 | 卯 |
| 寅 · 午 · 戌 | 火局 | 午 |
| 巳 · 酉 · 丑 | 金局 | 酉 |

（每局由"長生·帝旺·墓庫"三支組成，中神為帝旺之支。）

### 成實局的條件（本專案現行標準）
> **現行判定優先**：三合局只在初/三或四/上皆為動爻（明動或暗動），且這兩爻的支為局中兩支；
> 或三支中有一支在月建/日辰、其餘兩支皆為動爻時，才論實成。
> 靜爻不得拿來湊局，位置不合也不算；下文舊說若與此衝突，以此為準。

三合要論為**實成之局**（合力大、能化、可作決定性力量），須滿足以下任一：
1. **初爻、三爻同動**：這兩爻皆為動爻（明動或暗動），且這兩爻的支是局中兩支。
2. **四爻、上爻同動**：這兩爻皆為動爻（明動或暗動），且這兩爻的支是局中兩支。
3. **日月助成**：三支中有一支在月建或日辰，且其餘兩支都是動爻（明動或暗動）。

**關鍵：不是三支齊了就能成局。** 位置不對、或關鍵爻是靜爻，即使三支都在卦中，也只作「虛合」；
靜爻不能拿來湊「動變之局」。

### ⭐ 內卦三合局／外卦三合局（位置限定）

以「動爻＋變爻」湊局時，**位置有硬性限制**（不是卦中任何兩爻動了就算）：

- **內卦三合局**：**初爻、三爻皆為明動**——取這兩動爻的「原支＋變支」共四支，任三支成局，且**動支、變支必須並見**，即為內卦三合局。
- **外卦三合局**：**四爻、上爻皆為明動**，同理。
- **位置不對不能成局**：二、五爻動不成內/外卦局；初+三（或四+上）只動一爻亦不成。成局之支須取自該內／外卦那兩爻的動支與變支，**靜爻不能拿來湊「動變之局」**（暗動本質是靜爻，故亦不頂替明動）。
- 局名／五行／中神仍按上表；缺支由**變爻補出**者，原「虛合待填實」即升為**實成之局**。

> **例一（內卦）**：**天風姤** 初、三同動——初爻丑動、初化巳、三爻酉動 → **巳酉丑金局**。卦中本缺巳（原判虛合待填實），巳由初爻化出 → **實成之局**（內卦三合局）。
>
> **例二（外卦）**：**澤水困** 四、上同動——四爻亥動、上爻未動、上化卯 → **亥卯未木局**（外卦三合局）。
>
> **反例**：**地澤臨** 二、五同動，巳酉丑三支雖齊於卦中，但位置不合（非初+三、非四+上）→ 不成局，仍只作「支齊動不足」之虛合待用。

### ⭐ 虛合待用局（最易判錯）
當三支中**只有一爻（或零爻）是卦內動爻**，其餘靠**月建、日辰**（月日非卦內爻、本身不動）湊齊時：

- **不是實成三合局**，是"虛一待用"之合。
- 只能作**牽絆、糾纏之象**的輔助參考（合的意向在，故主有牽連、不易立刻斷），**不可斷"局已成、合化生世/克世"的決定性旺力**。
- 須**待流月/流日填實**（缺失之支當令、或卦中再有動爻加入）方能真正發力成局。
- 斷長期格局時，**勿把虛合的牽絆力度放大**為實局的合力。

### ⭐ 局之進階：破待填 · 拱而不出 · 入局從化

**（一）「破而待填」與「虛一待用」是兩種不同的「虛」**

| | 虛一待用 | 破而待填 |
|---|---|---|
| 局面 | 三支**缺支**（或卦內動爻不足），靠月日湊合 | 三支**卦中本齊**，但其中一支**月破** |
| 性質 | 局未成形——合的意向在 | 局形已備而力廢——局中一支無力參與 |
| 待什麼 | 待**缺字**值日/值月，或卦中再有動爻加入 | 待**破支**值日/值月（出月不復破，本支當令即修復） |
| 常見誤判 | 把意向當合力（放大虛合） | 把「支破」當「局缺」——誤以為局永不成 |

> **同卦兩局對照（本專案驗證卦例）**：亥卯未木局——亥（用神·靜）＋卯（世·動）＋未（月建），**缺字在卦外、動不足**→虛一待用；巳酉丑金局——巳（初爻·靜）＋酉（上爻·暗動）＋丑（三四爻兩重·**月破**），**支齊而一支破**→破而待填。兩局皆虛，虛法不同，填實路徑亦不同。

**（二）拱而不出：待用期間，所拱之字不作生克**

虛局待用期間，所待/所拱之字只是**伏而待發**——不是一個能拿去沖、克、合它爻的實支。**不得以「拱出某支」論生克沖合**（如謂"酉丑拱巳、巳沖亥"——巳未實，沖不成立）。

**（三）成局的另兩條路徑（補足前述條件）**

4. **靜爻臨值**：靜爻逢日辰同支（臨日建），力同發動；但本專案現行只把**明動/暗動**算入成局位置，靜臨值不單獨充當動爻，除非它正是日月助成的那一支。
5. **月日與動爻會局**：月建＋日辰＋卦中動爻（含暗動）湊齊三支，亦論會局（《增刪卜易》"動爻與日月會局"之法）。**本專案現行要求其餘兩支亦為動爻**，方作實成；若只有一支動，仍作虛合待用。

**（四）⭐ 入局從化（收編效應）：從局不從性**

局成而化，則**入局之支從局之化氣，不再以自身五行行生克沖合**——巳入金局則不為火：不克金、不沖亥；亥入木局則不為水。原支的一切生克關係（包括它本欲沖誰克誰）隨化而收。

**邊界（《增刪卜易》「局遇沖則散」）**：收編的是**主動**行克之權，不是該支的存在——局中一支若被日月**沖**之，則局散；**局散之後，各支復以本性行事**（巳火出局復能沖亥）。故「從局不從性」只在局存續期間成立，斷時須同時看局之成毀存續。

**判斷「局中某支會否沖剋用神」，先問局成不成：局未成，支自為支（破者無力）；局成，支隨局化——兩個答案常常相反。**

> 卦例：巳酉丑金局成（丑月填實破支＋巳日巳臨日建＋酉暗動）——巳火本為仇神、巳亥相沖，然入局化金後**不沖亥水，反與全域性共金生亥**：由"潛在沖剋者"收編為"生扶者"。同一天，局成與不成，巳對亥的角色截然相反——此即「**先問局，再問支**」。

**（五）失令局生（備用管道的應期價值）**

三合局常是用神的**備用生扶管道**：用神當令時自旺，不勞局生；**用神失令之月，恰是局中各支填實成局之時——局來接棒**。應期上，「用神衰」與「局待填實」兩通道若指向同一時段，該月用神「弱而不倒、局生生扶」，並可精確到**成局之日**（所待之支臨日建）斷強脈沖。應用詳見 12 冊通道表。

### 實成三合局的含義（須先滿足成局條件）
- 合力**大而專一**，化出之五行力量強，相當於一個強大的該五行之爻。
- 主**聚集、合夥、牽絆、糾葛**；合局之五行若為用神所需則大吉，為忌神則大凶。
- 合局也主**纏綿、拖延**（合住之意）。

> **經典例（本專案卦例）**：用神亥水（五爻·靜）+ 世爻卯木（二爻·動）+ 月建未土。三支亥卯未齊備，但**僅世爻卯一爻獨動**，亥為靜爻、未是月建（非卦內爻）。
>
> ⚠️ **據此只可論"虛一待用之合"**，不可斷"三合木局已成、合力聚世"。正確表述：有合的牽絆意向（緣分支在、有牽連，不至立刻斷絕），但未成實局，須待填實（如亥子月水生木、或再有動爻加入）方真正發力。化向為木（官鬼），即便成局也帶壓力，非純益。

## 二、六合（地支六合）

相鄰地支兩兩相合：

| 六合 | 化氣（參考） |
|---|---|
| 子 · 丑 | 土 |
| 寅 · 亥 | 木 |
| 卯 · 戌 | 火 |
| 辰 · 酉 | 金 |
| 巳 · 申 | 水 |
| 午 · 未 | 火（或土） |

### 六合的兩種作用
1. **合住（絆）**：爻被合住則**不能動**，主拖延、羈絆、停頓、糾纏不清。動爻被合則不能動彈（須沖開方動）。
2. **合起（助）**：衰爻逢合得助，或合化為旺相之五行而增力。

### 六合含義
- 主**和合、親近、牽連**。
- 占姻緣見合為吉（主和合親近）；占謀事見合住則主拖延不動。
- 用神與世爻相合 → 雙方親近、緣分深。
- 忌神與用神相合 → 忌神被絆住，暫不克用神，反吉（但合解則克復發）。

## 三、合與沖的實務

| | 主 | 含義 |
|---|---|---|
| 三合 | 聚集化一 | 合力大、專一、牽絆、合夥 |
| 六合 | 兩兩和合 | 親近、絆住、拖延 |
| 沖（六沖） | 散開動盪 | 變動、衝突、散、破 |

- **合逢沖則散**：合局/六合遇沖則解開（合住之爻遇沖則能動了；合局遇沖則散）。
- **沖逢合則止**：相沖之爻遇合則衝突暫止。
- 占事喜合忌沖（多數情況下，合主成、沖主變），但**合未必皆吉**（合住用神反主遲滯），**沖未必皆凶**（沖開墓庫、沖散忌神反吉）——要看合/沖作用在誰身上、對用神有利還是有害。

## 三·補、六合六法 / 六沖六法 / 爻沖五類

### 六合的六種情形（《增刪卜易·六合章》）
1. **日月合爻**：如丑月占，世爻子水與月建作合。
2. **爻與爻合**：兩動爻相合（須兩爻皆動，一爻不動不為合）。
3. **爻動化合**：動爻化出之爻與本身作合（化扶）。
4. **卦逢六合**：內外六爻自相和合（六合卦，不動亦是）。
5. **六沖變六合**：六沖卦變六合卦。
6. **六合變六合**：六合卦變六合卦。

**合的四態**：靜逢合＝**合起**（休囚逢合亦有旺意）；動逢合＝**合絆**（絆住不能動）；爻與爻合＝**合好**（他來合我、相助）；爻動化合＝**化扶**（得扶助）。

### 六沖的六種情形（《增刪卜易·六沖章》）
1. **日月沖爻**。2. **卦逢六沖**（六沖卦）。3. **六合變六沖**。4. **六沖變六沖**。5. **動爻變沖**。6. **爻與爻沖**。

沖主**散**：占凶事宜沖散，占吉事不宜。須兼用神——用神旺雖沖不礙，用神失陷則凶上加凶。**六合卦變六沖，用神縱旺亦始吉終凶**（有頭無尾）。

### 爻沖五類
- **月沖 ＝ 月破**。
- **靜爻旺逢日沖 ＝ 暗動**。
- **休囚逢日沖 ＝ 日破**。
- **動爻自化回頭沖 ＝ 如逢仇敵**。
- **爻與爻沖 ＝ 相擊**。
