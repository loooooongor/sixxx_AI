# 09 · 用神 · 元神 · 忌神 · 仇神 · 有力無力

斷卦以**用神**為核心，但用神能否得生、是否被克，要看**元神、忌神是否有力**。"見生不生""雖動不克"是六爻裡極常見、也極致命的誤判點——元神現了但無力，照樣生不起用神；忌神動了但無力，照樣克不到用神。本章把這套判定講透。

> 依據：《增刪卜易·用神元神忌神仇神章》。

## 一、四神定義（以用神爻五行為基準）

| 神 | 定義 | 對用神的作用 |
|---|---|---|
| **用神** | 所占之事對應的爻 | 主體 |
| **元神** | 生用神者（生我） | 生扶用神，吉 |
| **忌神** | 克用神者（克我） | 克損耗用神，凶 |
| **仇神** | 克元神、生忌神者 | 間接害用（制元助忌） |
| 閒神 | 與用神無直接生克 | 不主事 |

> 例：用神=金 → 元=土（生金）、忌=火（克金）、仇=木（克土元、生火忌）。
> 注意以**用神爻的五行**為基準（非六親），方符合"元生用、忌克用、仇克元生忌"的定義。

## 二、⭐ 元神有力五條（能生用神，諸占皆吉）

1. 元神**旺相**，或臨日月，或得日月動爻生扶。
2. 元神**動化回頭生**、及**化進神**。
3. 元神**長生、帝旺於日辰**。
4. 元神**與忌神同動**（忌動則元亦動以制之，反成生用之勢）。
5. 元神**旺動，臨空、化空**（旺不為空，待出空即生）。

## 三、無用元神六條（雖現，不能生用，雖有如無）

1. 元神**休囚不動**，或動而休囚又被傷克。
2. 元神休囚，又逢**旬空、月破**。
3. 元神**動化退神**。
4. 元神**衰而又絕**。
5. 元神**入三墓**。
6. 元神休囚，**動化絕、化克、化破、化散**。

> 要害：**"見生不生"**——元神現了但命中上述任一，則生不起用神，斷吉要打折扣。

## 四、忌神有力五條（能克用神，勢同斧鉞，諸占大凶）

1. 忌神旺相，或遇日月動爻生扶，或臨日月。
2. 忌神動化回頭生、化進神。
3. 忌神旺動，臨空、化空。
4. 忌神長生、帝旺於日辰。
5. 忌神與仇神同動。

## 五、忌神動不克用神七條（雖動，不能克用，化凶為吉）

1. 忌神休囚不動、動而休囚被日月動爻克。
2. 忌神靜，臨空破。
3. 忌神入三墓。
4. 忌神衰，動化退神。
5. 忌神衰而又絕。
6. 忌神動，化絕、化克、化破、化散。
7. **忌神與元神同動**（元神同動則制忌護用，忌神克力被化解）。

## 六、用神有根是前提

> **用神無根，謂之"元神有力亦難生、忌神無力亦休喜"。**

用神本身要有氣（得月生扶、臨日月、有動等）。若用神自身衰絕無根，則：元神再有力也"生不起一個死物"；忌神雖無力，用神自己也立不住，未必就能吉。故斷卦先看**用神有沒有根**，再看元忌有力無力。

## 七、仇神的作用

仇神不直接生克用神，但它**克元神**（使元神無力生用）、**生忌神**（助忌神克用），是用神的間接大敵。斷卦見仇神旺動，要警惕"元神被制、忌神得助"的連鎖。

## 八、引擎支援

- `board.line.role` 返回四神角色（用/元/忌/仇/閒）。
- 元神、忌神爻另有 `line.effective`（True 有力 / False 無力 / None 中和）與 `line.effective_reason`（理由），按上述有力/無力條件自動判定。
- `board.yongshen_wx` 為用神爻五行基準。

> 經典例（本專案卦例）：用神妻財亥水。
> - 子孫酉金 = 元神，**旺相暗動 → effective=True「發動有力」** → 能暗中生財（長輩撮合）。
> - 兄弟丑土 = 忌神，但**月破 → effective=False「月破無力」** → 雖是忌神卻克不到財（外部阻力被破）。
> - 父母巳火 = **仇神**（克金元、生土忌）。
> 這正是"元神有力則生、忌神無力則不克"的活用——若無這套判定，易誤判"有忌神就凶"。
