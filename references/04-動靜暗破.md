# 04 · 動靜暗破

旺衰定了"有沒有力"，本冊講"動不動、被不被破壞"——這是事情能否發動、有無阻礙的關鍵。**其中"暗動 vs 日破"是最易判錯、也最影響結論的一處。**

## 一、動靜

- **動爻（明動）**：占得老陽(☰⃝)/老陰(☓)之爻，主動變化，力量顯明，主事情有變。動則有化（見 05）。
- **靜爻**：少陽/少陰之爻，安靜不動，被動受生克。靜爻本不能主動生克他爻——**除非被日辰沖起而為"暗動"**。

## 二、月破

**月建所沖之爻為月破。**

地支相沖：子午沖、丑未沖、寅申沖、卯酉沖、辰戌沖、巳亥沖。

> 例：未月，未沖丑，故**丑為月破**；卯月，卯沖酉，酉為月破。

- 月破之爻**一月之內無力、衰敗、被破壞**，主散、主敗、主落空。
- 月破是**暫時**的——過月（出月）即恢復，不等於永久無用。
- 忌神月破為吉（阻力被破），用神/元神月破為凶（無力生扶）。
- 爻若本身旺相而被月沖，仍論月破，但因有根基，過月即復，損害較輕。

## 三、日破 與 暗動（核心）

**日辰所沖之靜爻**，分兩種命運，判據是該爻**旺衰**。

### ⭐ 暗動成立的條件（三條俱全）
1. **必須是靜爻**——被日辰沖的若是動爻，該爻早已發動，只論「動而愈動／動而沖散」，**不論暗動**。
2. **被日辰六沖**（爻支與日支成六沖）。
3. **爻本身旺相**——旺相＝月令旺相（旺／相）或得月日生扶、比和。**旺相 → 暗動；休囚死 → 日破。**

> **另一條來路：被動爻生助。** 靜爻雖不旺相，但**得卦中明動之爻生助**（動爻五行生此爻），逢日沖**亦作暗動**——動而生之，沖之不動反起。此與旺相逢沖同論有用。

### 暗動的用法
- 暗動之爻**等同於發動**，能生克他爻，**有用**。
- "暗"主不知不覺、隱秘、暗中。暗動主**暗中發力、暗中有人相助**。
- 暗動象意（精簡）：**暗中、背後推動**；**事情突然而起、出乎意料**；**未察覺之事悄悄發生**；**應期偏近、突發**。
- 寫法用「暗中發動」或「暗中推動」，不要寫成漂移不定之象。
- **元神（生用神者）暗動** → 暗中生助用神，**吉**。
- **忌神（克用神者）暗動** → 暗中克損用神，**凶**。
- 判暗動時**務必先辨該爻是元神還是忌神**，方能定吉凶。

### 日破（衰逢沖）
**靜爻休囚衰弱 + 被日辰六沖 = 日破（沖散）。**

- 衰弱 = 月令休／囚／死，且**無月日生扶或比和、亦無動爻生助**。
- 旺衰只看月令旺相休囚死（＋月日生扶比和），**十二長生不參旺衰**（長生/帝旺等階段僅供取象，見 03、13）。
- 日破之爻**被沖散、無用**，主敗、主散、主不成。

### 判定流程
```
靜爻被日沖 → 旺相嗎（月令旺相／月日生扶比和）？
                 是 → 暗動（有用，能生克他爻）
                 否 → 有明動之爻生此爻嗎？
                        有 → 暗動（得動爻生助）
                        無 → 日破（無用，沖散）
```

> **經典例（本專案驗證卦例）**：子孫酉金，未月（未土生金，金為「相」而旺），逢卯日沖 → **暗動**，非日破。作為元神暗中生助妻財亥水（金生水），是卦中隱性保底之力——主長輩介紹人暗中撮合。**若誤判為日破，結論將完全相反。**

## 四、空亡（旬空）

**以日辰查"旬空"**：日干支所屬的那一旬中，不出現的兩個地支即空亡。

### 旬空表
| 旬 | 空亡 |
|---|---|
| 甲子旬 | 戌、亥 |
| 甲戌旬 | 申、酉 |
| 甲申旬 | **午、未** |
| 甲午旬 | 辰、巳 |
| 甲辰旬 | 寅、卯 |
| 甲寅旬 | 子、丑 |

> 查法：日干支在哪一旬，該旬空兩個地支。如辛卯日屬甲申旬，空**午、未**。

### 空亡的論法
1. **日月建本身不以空論**——月建、日辰是主宰，不空。只看**卦中之爻**是否落空亡。
2. **卦中爻空**：
   - **旺相之爻空 = 假空**（旺不為真空），待出空/填實即有用。
   - **衰弱之爻空 = 真空/空而不實**，主虛浮、落空、不實、不成。
   - **真空的具體季節**（《增刪卜易》）：**春土、夏金、秋木、冬火**為真空——當季處死地又落旬空，到底全空；四季月（辰戌丑未，土當令）無真空。例：秋月（申酉）木爻落空為真空，冬月（亥子）火爻落空為真空。引擎以 `is_true_void` 判定。
3. **動而化空**：動爻變出空亡之爻，主事將成而落空，或暫時不能落實，待填實。
4. **空而逢沖 / 逢合 / 填實**：空亡之爻遇沖（沖空）、遇同地支之日（填實/出空）則空解，恢復作用。
5. 用神空：所占之事當下不實、未到位、暫虛；忌神空則禍未發，反吉。

> **實務要點**：先查**卦中六爻地支是否落旬空**。若卦中無落空之爻，則空亡不構成主要矛盾——這是常被忽略卻很重要的一步（很多人見"旬空"就大談空亡，實際卦中無爻落空，影響為零）。

## 五、速查：動靜暗破彙總

| 狀態 | 條件 | 含義 |
|---|---|---|
| 明動 | 占得老陽/老陰 | 顯性變化，能生克他爻，有化 |
| 暗動 | 靜爻 + 日沖 +（旺相 或 得動爻生助） | 隱性發動，有用，暗中發力 |
| 日破 | 靜爻休囚 + 日沖 + 無動爻生助 | 沖散無用，主敗 |
| 月破 | 月建所沖 | 一月內衰敗無用，過月可復 |
| 空亡(假) | 旺爻落旬空 | 暫空，填實則有用 |
| 空亡(真) | 衰爻落旬空 | 虛浮不實，主落空 |
